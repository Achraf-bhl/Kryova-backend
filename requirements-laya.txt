# Opt-in: the Laya intent router only (`AI_INTENT_ROUTER=laya`, off by default).
#
#   pip install -r requirements.txt -r requirements-laya.txt
#
# Laya (ConvAI Innovations, Apache-2.0) is a 421M non-autoregressive decision
# model: typed questions over a state, answered in one
# forward pass with a probability per option, never a token of text.
# `app/ai/laya_decide.py` is the one caller, and it imports both packages
# lazily. Without them the router fails open: the turn runs with the
# lexical tool selector alone and the log says why.
#
# Kept out of `requirements.txt` on purpose (2026-10-04), for three reasons:
#   1. It is a LOCAL model. The user's rule of 2026-10-04 is hosted models
#      only, so it is not switched on anywhere without the user confirming.
#   2. On Linux x86_64, PyPI's torch 2.5.1 is the CUDA build, not the CPU one.
#      It pulls the `nvidia-*` wheels, several GB, into every Docker image
#      and CI job that installs `requirements.txt`, for a feature none of
#      them turns on. A CPU-only machine wants
#      `pip install torch --index-url https://download.pytorch.org/whl/cpu`.
#   3. torch 2.5.1 publishes wheels for CPython 3.9-3.13 only. The Windows
#      seat runs 3.14, so with these pins in `requirements.txt`,
#      `scripts/setup.ps1` could not install anything there.
laya==0.3.11
torch==2.14.0  # 2.5.1 has no CPython 3.14 wheel; laya asks only torch>=2.0 (measured on the seat 2026-09-24)
